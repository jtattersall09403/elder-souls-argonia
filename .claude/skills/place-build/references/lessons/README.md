# Lessons (the operative store; decision 0100 decision 4)

Every placement lesson still in force, one table row each, split by section
(decision 0106): a lane reads the section its job needs, and orient reads
only the rows `site_packet` lists for its place's type (it reads every
section file here and derives the per-type list from the Types column).
Seeded 2026-09-25 by 16k slice 1b (16i item 0) from world 96 §2, which
keeps the history.

**How to write here.** One row per lesson in its section's file; a new
finding that restates a row edits that row. Columns: Id (`L<n>`; `new`
until the integrator numbers it) · Rule (an imperative) · Defect and cause
· Enforced by (the gate, test or `check` rule, or `prose only: <slice that
will mechanise it>`) · Shot (`plan`, `top`, `front`, `iso`; `walk` = only
the owner's walk shows it; `-` = not visual; `../reader-checklist.md` is
regenerated from the rows with a shot) · Source (owner walk, reader round,
compile refusal, or the record it came from) · Types (`type N`, `types N or
M`, or `all`).
