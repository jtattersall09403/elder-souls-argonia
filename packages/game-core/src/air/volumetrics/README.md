# volumetrics

One GPU froxel medium (WebGPU, TSL compute) for fog, mist, canopy shafts, light halos and interior mist; `fogField.ts` says where and when, `froxelGrid.ts` injects, lights and integrates, `volumetricNodes.ts` applies it in `scene.fogNode` and holds `sceneRadiance`.
Contract: [decision 0112](../../../../../docs/decisions/0112-gpu-volumetrics-froxel-fog-canopy-shafts-light-halos.md).
Harness shots: `cd apps/world-studio && node scripts/harness-run.mjs --backend webgpu --sys $(ls src/harness/scenes | grep '^volumetrics-' | sed 's/\.ts$//' | paste -sd,) --out <dir>`.
Window light (0112 §6): `windowApertures.ts` reads `interiorLight.json`, the one record of every published cell's windows, kind and dust band. **When you publish or re-publish an interior cell, run `python3 tooling/volumetrics/interior_light.py`** (all cells; `--cells <ids> --merge` for a few); `windowApertures.test.ts` goes red until you do. A cell whose derived dust band is wrong takes a row in the generator's `DUST_OVERRIDES` with a reason. Check a cell's light with `node scripts/harness-run.mjs --backend webgpu --sys interior-light --query "cell=<id>&facing=<door facingDeg>&t=08:00"` (from apps/world-studio).
