# Names we never reuse

Names invented by another mod: they belong to its author, and a player who knows that mod would
read them as borrowed. No world record, quest, NPC or text-catalogue string uses them. Canon
names that the same mod also uses (UESP has a page) stay ours to use.

The NPC set includes generic labels (for example "An-Xileel Guard", "Alit"). The ban covers
the personal names. A generic label or a canon creature or faction term is ours to use
wherever it rests on its own UESP page.
