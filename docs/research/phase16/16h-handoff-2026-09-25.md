## What changes on Codespaces

- `tooling/studio-loop/yard-publish.sh` prints URLs from `$ES_TUNNEL_URL`. In the codespace, `tooling/bootstrap/on-start.sh` derives it from `ES_STUDIO_PORT` (8081 in `.devcontainer/devcontainer.json`) as the forwarded-port URL.
- `tooling/repo-standards/memwatch.sh` now takes its ceiling from the machine limit (75 % of cgroup `memory.max`, else MemTotal), not the VM's fixed 12 GiB cgroup. Re-measure what one kit build and one miner run peak at before running two at once.
- Blender runs under Wine (`tooling/asset-pipeline/pipeline/config/toolchain.json`: `~/tools/wine-11.13-amd64-wow64`, `blender-4.4.3-windows-x64`, prefix `~/tools/wine-pynifly-prefix`); the workbench renders with a native Linux Blender 3.2.2. Both must exist in the codespace (bootstrap tiers).
- The vault (`elder-scrolls-asset-pipeline`) is resolved by `pipeline/vault_path.py`: `ELDER_SOULS_ASSET_ROOT`, else the repo's sibling, else `~/workspace/elder-souls-dev/elder-scrolls-asset-pipeline`. `ES_ASSET_PIPELINE_ROOT` has two meanings and must stay unset in a codespace (PROGRESS Codespaces row, item 5).
- Memory: copy the project folder's `memory/` into `~/.claude/projects/<the codespace's project folder>/memory/` (the folder name is the repo path with `/` as `-`, e.g. `-workspaces-elder-souls-argonia`); `MEMORY.md` is its index.
- Environment: `ES_STUDIO_PORT` (8081) comes from the dev container; `ES_TUNNEL_URL` is the forwarded-port URL, set by `on-start.sh`. On the VM both lived in the gitignored `.claude/settings.local.json` `env`.
- The Nexus key is read from `~/.config/nexus/api_key`; copy it by hand, never into the repo.
- Lane reports went to `/tmp`, which a codespace does not keep across rebuilds. Proposal: write them to `tooling/.reports/<lane>/` and add that path to `.gitignore` (not done here; the planner decides).
- `.claude/review-findings-<key>.md` files are not ignored (`.gitignore:32–33` lists only the two fixed names); 17 were left untracked at the cut, with a copy in `~/handoff/elder-souls-handoff-2026-09-25/leftovers/review-findings/`.
